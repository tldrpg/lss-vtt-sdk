# Демо API персонажа

Демо встраивает открытый лист Long Story Short через `@longstoryshort/vtt-sdk`.
Панель показывает HP и позволяет проследить команду от локального применения до подтверждения
записи на сервере. Список атак и заклинаний доступен из меню токена персонажа. Демо подключает
`createBridgeSheetSource` с `characterApi: { sheetOrigin }` и читает снимок и результаты через
`source.character`. В режиме мастера демо отправляет урон из браузера мастера в открытый
лист игрока. Для этой команды источник SDK подключается к iframe управления группой с
`roomCharacters: { sheetOrigin }` и ждёт результат через `source.roomCharacters`.

## Локальный запуск

Запустите Storyview на `https://localhost:8000` с локальным API. Подготовьте HTTPS-сертификат
для `localhost` или используйте сертификат из каталога `storyview/.cert`. Среда Node указана
в `.nvmrc` репозитория SDK.

Из корня SDK соберите пакет и установите зависимости демо.

```sh
npm ci
npm run build
cd bridges/character-api-demo
npm ci
```

Для соседних рабочих копий SDK и Storyview запустите демо из каталога `bridges/character-api-demo`.

```sh
VITE_SHEET_URL=https://localhost:8000/iframe/characters/list/ \
DEMO_TLS_CERT=../../../storyview/.cert/localhost+2.pem \
DEMO_TLS_KEY=../../../storyview/.cert/localhost+2-key.pem \
npm run dev
```

Откройте `https://localhost:5173` и нажмите «Выбрать группу». В iframe можно выбрать
свою группу или создать новую. После выбора демо предложит вступить в неё через открытый
лист. Откройте своего тестового персонажа и подтвердите вступление в листе. Снимок и команды
станут доступны после подтверждения группы.

Для тестовых прогонов параметр URL `?groupCode=<код>` сразу задаёт группу. В режиме Vite dev
параметр `character=<id>` открывает цифровой лист персонажа. Демо передаёт код через
`lss:group-code` и показывает состояние по `lss:group-status`. Выбранная группа хранится
в памяти страницы, включая закрытие и повторное открытие листа.

## Мастер и игрок в двух браузерах

1. В браузере мастера нажмите «Режим мастера» и «Выбрать группу». Войдите в LSS в iframe и
   выберите свою группу или создайте новую. В странице группы скопируйте код приглашения.
2. В отдельном профиле браузера откройте демо игрока с `?groupCode=<код>`. Войдите в другой
   аккаунт LSS, откройте своего тестового персонажа и подтвердите вступление в листе.
3. Оставьте лист игрока открытым. В браузере мастера выберите персонажа группы, введите величину
   урона и нажмите «Нанести урон». Дождитесь «Урон сохранён сервером» в журнале мастера и
   сверьте HP в переоткрытом листе игрока.
4. «Повторить тот же ID» запрашивает результат той же команды. После выхода персонажа из группы
   мастер видит обновлённый состав.

Для прямого открытия режима мастера используйте
`?mode=master&groupCode=<код>`. В этом режиме демо открывает страницу управления
`/iframe/group/?roomCommands=1`. Состав приходит после проверки аккаунта мастера в LSS.
Пока лист игрока закрыт, команда ожидает исполнения до истечения срока. «Исход неизвестен»
означает, что исполнение могло начаться, а подтверждение сохранения ещё не получено.

## Что проверить в листе игрока

1. Нанесите урон. Из 10 текущих и 4 временных HP после урона 8 останется 6 текущих и
   0 временных. В журнале сначала появится `applied`, затем `saved` с покрывающей ревизией.
2. Нажмите «Повторить тот же ID». У той же строки увеличится счётчик отправок,
   а текущие HP останутся равными 6.
3. Поменяйте HP внутри iframe и сверьте новый снимок. Закройте лист, чтобы проверить
   состояние подключения. При новом открытии демо использует существующее членство в группе.
4. Откройте персонажа вне выбранной группы. Снимок и команды появятся после вступления.
5. Нажмите токен «Персонаж» или откройте его контекстным кликом. Сверьте атаки,
   модификаторы и заклинания с листом. Для заклинания с привязанным ресурсом видны остаток
   заряда и кнопка «Потратить заряд».
6. Потратьте заряд и дождитесь `saved`. Повтор прежнего ID сохранит остаток. При нуле
   кнопка нового расхода недоступна. Команда `spell.spend-charge` меняет заряд в листе.
7. В меню токена выберите «Бросок атаки», «Бросок урона» или выберите характеристику
   и нажмите «Спасбросок». Лист выполнит бросок, а журнал покажет формулу и итог из
   ответа `rolled`. Кнопка «Повторить тот же ID» вернёт исходный результат в той же
   сессии. Бросок урона вычисляет число для стола. HP выбранной цели меняет команда
   применения урона.
8. Выберите характеристику или навык в выпадающем списке и запустите соответствующую
   проверку. «Бросок инициативы» использует текущую инициативу листа. Все три действия
   показывают результат `rolled` в журнале.
9. В разделе «Ресурсы» поменяйте счётчик кнопками `−1` и `+1`. Снимок показывает
   текущее значение и, если задан, максимум. Дождитесь `saved` и сверьте значение
   после повторного открытия листа. Повтор того же ID оставит значение прежним.

«Копировать JSON» копирует разрешённый снимок, команды и результаты из памяти страницы.
Если сервер ещё не подтвердил запись, `unknown` означает, что её исход нужно сверить.
В той же сессии повтор прежнего ID позволяет запросить известный результат.

## Сборка

```sh
npm run build
```

Сайт собирается в `dist/` с путём `/dnd/character-api-demo/`. Без
`VITE_SHEET_URL` он открывает лист на `https://longstoryshort.app`. Путь публикации
добавлен в существующий workflow мостов.

[Инструкция для интеграторов](https://longstoryshort.app/doc/developers/embedding/character-api-demo/)
